## 二、 核心关键技术方案设计

### 2.1 OFA 硬件光流与运动矢量注入架构
```text
  Frame(t-1) 纹理池 ──┐
                     ├──> [ NVIDIA OFA 硬件电路 (0.8ms) ] ──> Dense MV 纹理 (DXGI_FORMAT_R16G16_FLOAT)
  Frame(t)   纹理池 ──┘                                                │
                                                                       ▼
                                                          [ nvngx_dlssnr (DLSS 5) ]
                                                                       ▲
                                                                       │
  Frame(t)   线性化纹理 (Linear FP16) ─────────────────────────────────┘
```
- **接口调用**：通过 NVIDIA Optical Flow SDK 或 D3D12 DirectML Optical Flow 创建 `NV_OF_EXECUTE_INPUT_PARAMS`；
- **精度配置**：采用 `NV_OF_PERF_LEVEL_FAST`，网格分辨率选择 1x1 或 2x2（像素级稠密光流），完全满足时序重构的亚像素位移匹配。

### 2.2 144Hz 双速率解耦合成器与交互状态机设计
```text
  [ 线程 A: 视频渲染主线程 ] ──> 24/30fps ──> 更新 D3D12 共享双缓冲纹理 (TexA, TexB)
                                                     │
                                                     ▼
  [ 线程 B: UI 交互合成线程 ] ──> 144Hz+ ──> 监听 pointermove ──> 刷新 Uniform_WipeRatio
                                       └──> HLSL 像素着色器以显示器满血帧率合成呈现
```
- **交互状态表**：
  - **HOVER_ACTIVE**：鼠标在视口内移动，擦除线以 144Hz 满血跟随光标，青色微光边高亮；
  - **STICKY_HOLD**：鼠标移出视口，擦除线保持在离开位置，微光边半透明渐隐；
  - **FROZEN_COMPARE**：用户单击视口进入瞬时定格，视频暂停；此时响应鼠标滚轮，调用解码器精确 seek 逐帧穿梭（`target_pts += frame_duration`）。

### 2.3 4GB~8GB 显卡显存预算重校（总封顶 $\le 3.4	ext{GB}$）

| 显存分项 | 额定显存占用 (MB) | 说明 |
| :--- | :--- | :--- |
| **NVDEC 解码表面池** | 220 MB | 环形复用 4 帧 NV12 |
| **NVIDIA OFA 光流表面** | 80 MB | 前后两帧参考及运动矢量输出 |
| **D3D12 1080P 神经中间层** | 160 MB | 乒乓双缓冲 Linear FP16 |

| **系统 DWM 与驱动上下文** | 600 MB | Windows 桌面驱动预留 |
| **【峰值显存锁定】** | **$pprox 3,180	ext{MB}$** | **完全在 4GB（4096MB）安全线内，留出 $\ge 800	ext{MB}$ 冗余** |

## 三、 预览与导出并发互斥设计 (Exclusive Session Manager)

```cpp
enum class AppWorkMode { Idle, InteractivePreview, BatchExporting };

class SessionCoordinator {
public:
    void StartBatchExport() {
        m_mode = AppWorkMode::BatchExporting;
        // 1. 通知预览播放器注销独立硬解流与交换链，释放 350MB 显存
        m_previewPlayer.EnterSnapshotProxyMode();
        // 2. 独占分配所有 NVDEC/NVENC 会话给导出引擎
        m_exportEngine.AcquireExclusiveHardwareSessions();
    }
    
    // 导出中若前端需要展示当前进度画面：
    void OnExportFrameFinished(ID3D12Resource* p4kTexture) {
        // 直接借用当前已完成的 4K 显存纹理降采样推送，显存增量为 0
        m_previewPlayer.UpdateProxyThumbnail(p4kTexture);
    }
};
```
