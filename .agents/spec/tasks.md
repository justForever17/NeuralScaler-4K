# 【NeuralScaler-DLSS5 桌面视频超分工具】研发任务分解与里程碑规划 (Tasks Spec)
> 版本：v2.2-Refined | 状态：任务拆解与全覆盖测试门禁锁定 | 实施周期：6 周 (Sprint 0 ~ 5)

## 一、 里程碑阶段目标 (Milestone Overview)

```text
Sprint 0 (Week 1): 核心工程骨架与基础通信链路 (M0)
   └── C++20 工程骨架、Named Pipe JSON-RPC 协议、Win32 宽字符与 UTF-8 基础引擎
Sprint 1 (Week 2): 4-8G 显存硬件超分全闭环管线 (M1)
   └── NVDEC 硬解 ➔ OFA 光流硬件加速 ➔ CS 线性化 ➔ DLSS 5 1080P 归一化 ➔ RTX VSR 4K 放大 ➔ NVENC 硬编
Sprint 2 (Week 3): 现代 Win11 Fluent 2 桌面前端与丝滑交互 (M2)
   └── Tauri 2.0 + React 19、Mica Alt 材质、144Hz 双速率 Wipe 悬停擦除播放器、单击冻结与滚轮逐帧穿梭
Sprint 3 (Week 4): Fallback 容错保底与并发互斥熔断系统 (M3)
   └── 三级输出目录 Fallback、会话互斥管理器、VRAM/TDR/磁盘/坏帧四级熔断看门狗
Sprint 4 (Week 5): 路径覆盖与条件组合覆盖 (MCC) 测试套件 (M4)
   └── 覆盖真值表矩阵、白盒 OFA/Fallback 单元测试、黑盒 E2E 画质验收、反例注入夹具
Sprint 5 (Week 6): 便携版 EXE、WiX MSI 安装包构建与交付 (M5)
   └── 单文件便携版打包、MSI 安装包定制（快捷方式/右键扩展）、真机多卡基准压测
```
