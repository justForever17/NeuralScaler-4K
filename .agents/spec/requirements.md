# 【NeuralScaler-DLSS5 桌面视频超分工具】产品需求规范文档 (Requirements Spec)
> 版本：v2.2-Refined | 状态：OFA光流硬件闭环、1080P归一化、144Hz解耦擦除与并发互斥全锁定 | 平台：Win 10/11 x64 (RTX 4-8G)

---

## 一、 产品愿景与技术路线审视锁定

### 1.1 核心初始条件与两阶段算力分层
本项目严格锁定初始条件：**“低分辨率阶段先用 DLSS 5 进行神经增强，再用高效硬件时序超分（RTX VSR）拉升至 4K”**。
通过深度技术架构审计，排查并彻底解决四大底层断点：

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        NeuralScaler-DLSS5 完整闭环视频管线                             │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 1. 硬件硬解 (NVDEC) ──> 输出 NV12 (8/10-bit) 显存表面                                  │
│                                │                                                       │
│                                ▼                                                       │
│ 2. 硬件光流 (NVIDIA OFA) ─> 利用 RTX 专用光流引擎，毫秒级输出像素级稠密运动矢量 (MV)   │
│                                │ (彻底根除 2D 视频无 G-Buffer 导致的鬼影与时序形变!)   │
│                                ▼                                                       │
│ 3. 预处理着色器 (CS) ────> 色彩空间线性化 (NV12 ➔ Linear FP16) + 双边去块滤波          │
│                                │                                                       │
│                                ▼                                                       │
│ 4. 阶段一：DLSS 5 神经材质生成 (1080P 归一化中间层)                                    │
│    ├── 输入 1080P: 原地 DLAA 神经重构 (1:1)，注入高保真微观毛孔、发丝光影、次表面散射 │
│    ├── 输入 720P:  Quality 模式 (1.5x) 神经超分至 1080P                                │
│    └── 输入 480P:  Ultra Perf (2.25x) 神经超分至 1080P (附黄色警示 Badge + 弱引导防变形)│
│                                │ (全部统合至 1080P 高清神经中间层，显存仅需 ~1.2GB)    │
│                                ▼                                                       │
│ 5. 阶段二：RTX VSR 硬件时序放大 ──> 将 1080P 神经中间层极速拉升至 4K (3840x2160, ≤1.8ms)│
│                                │                                                       │
│                                ▼                                                       │
│ 6. 硬件硬编 (NVENC) ──> 注入 BT.709 VUI 元数据，输出 4K MP4 (结合 faststart 无损混流) │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

1. **【断点闭环 1：OFA 硬件光流补齐运动矢量】**：
   - 2D 视频无游戏引擎深度与运动矢量。本项目通过调用 NVIDIA RTX 硬件上的 **NVIDIA Optical Flow Accelerator (OFA)**，在 1080P 下仅耗费 $\approx 0.8\text{ms}$ 硬件专用电路，生成像素级连续运动矢量场（Dense Motion Vectors），彻底根除人物眨眼、转头时的鬼影拉丝与面部时序撕裂。
2. **【断点闭环 2：1080P 归一化神经中转】**：
   - 杜绝任意尺度直接超分到 4K 导致算力雪崩与感知野错配。所有源视频（480P/720P/1080P）在第一阶段统一由 DLSS 5 重建/超分至 **标准 1080P 神经中间层**，第二阶段统一由专有 RTX VSR 2x 硬件通道高速输出至 4K，兼顾极致质感与 4-8G 显存极速吞吐。
3. **【断点闭环 3：色彩空间与动态范围无损映射】**：
   - 在进入 DLSS 5 前通过计算着色器将 NV12 展开为 Linear FP16 线性物理空间，避免暗部死黑与高光失真；在 NVENC 编码前严格注入 BT.709 VUI 广播级色彩元数据。
4. **【断点闭环 4：导出引擎与预览播放器会话互斥 (Exclusive Session)】**：
   - 在 4GB 显存卡（如 RTX 3050）上，禁止同时运行两路独立的重型 NVDEC/DLSS 5 会话；导出时交互播放器自动切换为“低频抽样快照代理模式”，显存零额外增长，100% 算力归还批处理导出。

## 二、 极致丝滑的产品形态与操作手感规范

### 2.1 效仿 VideoComparerMEC 的双速率 Wipe 鼠标悬停动态擦除播放器
- **FR-UI.1 144Hz 双速率解耦合成器 (Dual-Rate Decoupled Wipe)**：
  - **核心痛点**：视频源仅 24/30fps，若擦除线跟随视频帧刷新，鼠标滑动会有严重顿挫卡顿。
  - **解耦技术规范**：视频解码与 DLSS 5 在后台以源帧率（24/30fps）生成并更新双显存纹理；而前景 Wipe 擦除分割线与微光边由系统/DirectComposition 独立运行于 **显示器原生最高刷新率（60Hz / 120Hz / 144Hz / 165Hz）**，鼠标在视口内移动时达到 **0 延迟、144Hz 满血丝滑手感**。
- **FR-UI.2 鼠标悬停跟随与离开定格模式 (Hover Tracking with Sticky Memory)**：
  - 光标进入播放器视口后，**无需任何按住拖拽动作**，实时以光标 X 轴相对坐标作为分割线；
  - 分割线具备 1px 亮青色（#00C8FF）微光边，对比边缘极其锐利清晰；
  - **离开定格特性**：鼠标移出视口时，擦除线**保持停留在离开时的坐标位置**，微光边平滑渐变为半透明柔光，确保用户移去侧边栏调整参数时对比基准不被破坏；双击视口恢复居中（50%）。
- **FR-UI.3 点击即时定格与滚轮逐帧穿梭 (Click-to-Freeze & Wheel Scrubbing)**：
  - 动态视频人眼难以聚焦微观毛孔细节。
  - 用户在视口内**单击即可瞬时定格（Pause）当前帧**，实现静止状态下的微观擦除审视；
  - 定格状态下，**滑动鼠标滚轮可前后逐帧穿梭（+1 Frame / -1 Frame）**，方便精准定位人物高光特写进行对比。
- **FR-UI.4 惰性点击加载与显存自动休眠**：
  - 默认仅加载轻量海报帧（首帧缩略图，显存 $\\le 15\\text{MB}$）；
  - 仅当用户激活播放时才分配硬件解码池，无操作闲置 5 秒后自动释放工作集显存。

### 2.2 系统原生文件/目录选择交互
- 彻底摒弃纯文本路径输入框；
- 输入通过 Win32 原生文件对话框（`.mp4` 过滤器）或拖拽载入；
- 输出通过 Win32 原生文件夹选择器指定，并配套只读 Fluent 面包屑与【在资源管理器中定位】快捷键。

## 三、 健壮性 Fallback 保底与四级主动熔断规范

### 3.1 三级输出目录 Fallback 与冲突解决
1. **Tier 1**：用户原生选择器指定的有效可写目录；
2. **Tier 2（默认保底）**：未指定时，自动 Fallback 至输入视频同级目录下的 `output_4k\` 文件夹；
3. **Tier 3（只读系统保底）**：输入视频处于光盘或受限目录时，平滑 Fallback 至 `%USERPROFILE%\Videos\NeuralScaler\`；
4. **同名文件冲突保底**：自动递增编号 `{filename}_4K_DLSS5 (1).mp4`，绝不静默破坏原有文件。

### 3.2 四级工业级极限场景主动熔断看门狗
1. **显存枯竭熔断**：实时探测可用显存，跌破 $300\text{MB}$ 立即挂起任务并释放预览暂存，杜绝蓝屏死机；
2. **GPU TDR 崩溃自愈**：捕获 `DXGI_ERROR_DEVICE_RESET`，保存批处理断点，3 秒内重新枚举设备并无损恢复；
3. **磁盘打满/写入卡顿熔断**：输出驱动器剩余可用容量 $< 500\text{MB}$ 时立即暂停并保护已转码文件；
4. **单帧坏流死锁看门狗**：单帧 NVDEC 硬解或 DLSS 5 计算耗时超过 $500\text{ms}$（正常为 20ms）判定死锁，看门狗强制跳过该坏帧（Frame-Hold 前一帧画面）继续处理，批处理绝不卡死。

## 四、 交付前测试覆盖标准 (MCC & Path Coverage)

必须在 `tests/` 目录下完成 100% 的自动化夹具验证，提供真实的通过依据方可合流交付：
1. **白盒测试套件 (`tests/unit/`)**：
   - 视频元数据与流结构精准提取（UT-01）；
   - 三级 Fallback 链条与同名递增算法判定真值表（UT-02）；
   - 显存预算、TDR 自愈与四级熔断状态机（UT-03）；
   - BT.709 VUI 标签与 faststart 头部规范（UT-04）；
   - OFA 硬件运动矢量提取模拟与 144Hz 双速率解耦测试（UT-05）。
2. **黑盒端到端与画质验收 (`tests/e2e/`)**：
   - 720P/1080P 标准视频全流程超分与无损音频 Stream-Copy 对齐（$\\Delta t \\le 10\\text{ms}$）；
   - 客观画质指标验收：PSNR 相比双三次插值提升 $\\ge 2.5\\text{dB}$，SSIM 提升 $\\ge 0.08$。
3. **反例与故障注入测试 (`tests/negative/`)**：
   - 0 字节、坏文件、假后缀 100% 拦截；
   - 480P 输入 100% 弹出微观形变黄色警示 Badge；$<480\text{P}$ 与 $\\ge 4\text{K}$ 100% 拦截。
